# Overview

As a software engineer in training, I wanted to confirm that my development environment is working from start to finish, from writing code to publishing it on GitHub, while getting my first look at the Kotlin language.

This is a small Kotlin program that prints "Hello World!", introduces me, and shows today's date. It uses a function, a variable, string templates, and the Java time library that Kotlin can use.

My purpose in creating this software was to practice the full workflow I will use for all my projects: writing and commenting code, documenting it in a README, recording a video walkthrough, and publishing it in a public repository.

[Software Demo Video](http://youtube.link.goes.here)

# Development Environment

I wrote the program in Visual Studio Code and used Git for version control, with the code hosted on GitHub. I compiled it with the Kotlin command-line compiler and ran it on the Java Development Kit.

The program is written in Kotlin and uses the `java.time` library for the date.
